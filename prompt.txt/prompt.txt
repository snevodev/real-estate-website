# Vibe Engineering Using Multiple Prompts

 Project: Zara Prime Realty – Luxury Real Estate Website

LLM Used: (ChatGPT)

## PROJECT OVERVIEW

This project demonstrates the use of **Vibe Engineering** by guiding ChatGPT through a sequence of carefully structured prompts to generate different components of a modern luxury real estate website. Rather than relying on a single prompt, I progressively refined the project using multiple prompts, then manually reviewed, tested, customized, and improved the generated code to produce a professional, portfolio-ready website.



# PROMPT ENGINEERING PROCESS:

# Prompt 1

ChatGPT, please I am a software developer. Help me create a modern luxury real estate website called Zara Prime Realty that I can add to my portfolio.

# Prompt 2

Create a responsive homepage (index.html) with a professional navigation bar, hero section, property search form, featured properties section, agents section, and footer.

# Prompt 3

Design a luxury hero section with a high-quality estate background image, compelling headline, call-to-action buttons, and modern styling.

# Prompt 4

Create a responsive property search form that allows users to search properties by location, property type, and price range.

# Prompt 5

Create a featured properties section displaying luxury properties using responsive property cards.

# Prompt 6

Design a Why Choose Us section that highlights premium services, trusted agents, and customer satisfaction.

# Prompt 7

Create a Meet Our Agents section displaying professional real estate agents.

### Prompt 8

Create an About Us page (about.html) that introduces Zara Prime Realty, including the company story, mission, vision, and values.

# Prompt 9

Create an Agents page (agents.html) showcasing all available real estate agents in a professional grid layout.

# Prompt 10

Create an Agent Profile page (agent-profile.html) displaying an agent biography, contact information, experience, skills, and listed properties.

# Prompt 11

Create a Listings page (listings.html) displaying all available properties with filters and search functionality.

# Prompt 12

Create a Property Details page (property-detail.html) showing property images, descriptions, amenities, specifications, and contact information.

#Prompt 13

Create a Search Results page (search-results.html) displaying properties that match user search criteria.

### Prompt 14

Create a Blog page (blog.html) focused on real estate news, investment tips, property trends, and luxury living.

# Prompt 15

Create a Contact page (contact.html) with a contact form, company information, office location, and map section.

### Prompt 16

Create an Authentication page (auth.html) containing modern Login and Registration forms.

# Prompt 17

Create a Dashboard page (dashboard.html) where users can manage saved properties, inquiries, and account information.

# Prompt 18

Create a professional navigation menu with dropdown items linking to:

* Home
* About Us
* Listings
* Property Details
* Search Results
* Agents
* Agent Profile
* Blog
* Contact
* Authentication
* Dashboard

#Prompt 19

Make the navigation menu sticky so it remains visible while users scroll.

# Prompt 20

Create a professional footer containing company information, quick links, contact details, and social media links.

# Prompt 21

Ensure the footer remains consistent across all pages and matches the luxury branding.

# Prompt 22

Use the following luxury color palette:

* Navy Blue (#0F172A)
* Gold (#D4AF37)
* White (#FFFFFF)
* Light Gray (#F8FAFC)

# Prompt 23
Use modern typography, spacing, shadows, and visual hierarchy to create a premium user experience. Implement smooth hover effects, transitions, and animations throughout the website.

# Prompt 25
Ensure every page is fully responsive across desktop, tablet, and mobile devices. Use CSS Grid and Flexbox to build modern, responsive layouts.
